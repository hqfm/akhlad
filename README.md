# Mohd Akhlad — My Projects

A small personal project page made by **Mohd Akhlad**.

The site is a simple collection of things I made while learning HTML, CSS, JavaScript, and experimenting with different ideas.

## Projects

### 🪐 Solar System Explorer

**File:** `solar.html`

An interactive Solar System Explorer where you can learn about the Sun, planets, dwarf planets, moons, asteroids, and other interesting parts of our Solar System.

### `</>` My Code Translator

**File:** `encoder.html`

A small English ↔ custom-code translator. It converts English letters into a custom numeric code and can also convert the code back into English.

## Files

```text
.
├── index.html      # Main project homepage
├── solar.html      # Solar System Explorer
├── encoder.html    # Code Translator
├── 404.html        # Custom 404 / page-not-found page
└── README.md       # This file
```

## Running it

No installation is needed.

Just open `index.html` in a browser.

If you are hosting it with GitHub Pages, put all the files in the same repository and enable GitHub Pages.
